## Возможности

88 тем, 103 иллюстрации, выбор вариантов, настройка яркости стартового экрана и фона за текстом.
Палитра применяется к чату, боковой панели и штатным настройкам. Подсветка кода сохраняется.
Язык следует языку Codex: 65 локализаций в проверенной версии.

Выбор стандартной темы Codex отключает Doki. В поле темы появляется «Не выбрана».
Выберите любую тему Doki, чтобы включить оформление снова. Предпочтения сохраняются.

## Установка

Это экспериментальная, неофициальная модификация. Установщик создаёт отдельную копию Codex,
меняет её архив и исполняемый файл; исходная подпись изменённого файла перестаёт быть действительной.
Приложение из Microsoft Store остаётся нетронутым.

Понадобятся:

1. Windows и установленный Codex. Проверена внутренняя версия **26.1002.52244**,
   пакет Microsoft Store **26.1002.7124.0**.
2. [Python 3.10+](https://www.python.org/downloads/windows/), доступный через `py` или `python`.
3. Установленное в VS Code расширение [Doki Theme](https://marketplace.visualstudio.com/items?itemName=unthrottled.doki-theme),
   проверена версия **88.1.18**.
4. Минимум **3 ГБ** свободного места и интернет для иллюстраций, которых нет в кэше расширения.

Распакуйте ZIP релиза и запустите **Install.cmd**. Дождитесь завершения копирования.
Для запуска откройте `%LOCALAPPDATA%\CodexDoki\Start-Doki.cmd`.
Затем меню профиля → Настройки → Внешний вид → Doki Theme.

Права администратора и дополнительные пакеты Python для стандартной установки не нужны.
Codex и иллюстрации не включены в релиз: используются локальная установка и официальный сервер Doki.
В некоторых темах оригинального расширения встречаются иллюстрации для взрослых.

Копия использует отдельный профиль интерфейса `Codex-Doki`; может потребоваться вход.
Проекты, история чатов и служебный каталог `.codex` могут быть общими с основным Codex.

## Проверка, обновление и удаление

```powershell
py -3 install.py check
py -3 install.py install --offline
py -3 install.py uninstall
```

`check` проверяет совместимость без копирования приложения и скачивания картинок.
`--offline` использует только кэш Doki. Для нестандартных путей доступны `--codex-path`,
`--extension-path`, `--cache-path`, `--install-dir` — подробности в `py -3 install.py --help`.

Для удаления закройте копию и запустите **Uninstall.cmd**. При нестандартном пути передайте
его через `--install-dir`. Профиль интерфейса, чаты и проекты сохраняются.
Для обновления удалите копию и создайте её снова. Копия не обновляется вместе с Microsoft Store.

Другие версии Codex не проверены: экспериментальная установка требует `--allow-unsupported`.
Проверки структуры архива остаются обязательными. [Ограничения и диагностика](docs/COMPATIBILITY.md).
