## Возможности

88 тем, 103 иллюстрации, выбор вариантов, настройка яркости стартового экрана и фона за текстом.
Палитра применяется к чату, боковой панели и штатным настройкам. Подсветка кода сохраняется.
Язык следует языку Codex: 65 локализаций в проверенной версии.

Выбор стандартной темы Codex отключает Doki. В поле темы появляется «Не выбрана».
Выберите любую тему Doki, чтобы включить оформление снова. Предпочтения сохраняются.

## Свои темы (версия в разработке)

Откройте **Настройки → Внешний вид → Doki Theme → Свои темы → Создать тему**.
Введите уникальное название, выберите цвета фона, текста и акцента, при желании загрузите картинку и нажмите **Сохранить и применить**.
Свои темы появятся рядом с темами Doki в общей галерее с превью. **Изменить тему**, **Удалить тему** и **Экспорт JSON** работают с выбранной своей темой; **Импорт JSON** загружает ранее экспортированный файл.

Свои темы сохраняются локально в профиле Codex Doki без искусственных ограничений на размер файла и количество тем. Фоны PNG, JPEG и WebP автоматически оптимизируются, если весят больше 2 МБ или превышают 3840 пикселей: WebP с качеством 90%, до 3840 пикселей по длинной стороне, с сохранением пропорций и прозрачности. В редакторе показан размер до и после. Отключите **Оптимизировать тяжёлые фоны**, чтобы сохранить исходные байты. Маленькие файлы не меняются; сжатая версия используется только если она меньше оригинала. Оптимизация работает при загрузке и импорте JSON; для уже сохранённого фона откройте **Изменить тему** и сохраните её. Исходные файлы на диске не изменяются. Акцент автоматически подбирается из цветов картинки; ручной выбор цвета отключает автоподбор, а переключатель включает его снова. JSON содержит саму картинку: передавая файл, вы передаёте и фон. Повторяющиеся названия запрещены. Сброс настроек оформления не удаляет сохранённые темы. Выбор штатной темы по-прежнему отключает Doki; автоматическая коррекция контраста работает и для своих цветов. Выбранная тема и её настройки дополнительно сохраняются в постоянной базе тем и восстанавливаются после полного перезапуска приложения.

Редактор следует языку Codex: доступны английские и русские подписи, для остальных языков новые элементы отображаются на английском. Возможность пока доступна в исходниках и локальной версии в разработке; ранее опубликованный ZIP 0.1.1 её не содержит.

## Установка

Это экспериментальная, неофициальная модификация. Установщик создаёт отдельную копию Codex,
меняет её архив и исполняемый файл; исходная подпись изменённого файла перестаёт быть действительной.
Приложение из Microsoft Store остаётся нетронутым.

Понадобятся:

1. Windows и установленный Codex. Проверена внутренняя версия **26.1002.52244**,
   пакет Microsoft Store **26.1002.7124.0**.
2. [Python 3.10+](https://www.python.org/downloads/windows/), доступный через `py` или `python`.
3. Минимум **3 ГБ** свободного места и интернет для первой установки.

**VS Code и расширение Doki устанавливать не нужно.** Каталог тем включён в пакет;
установщик автоматически скачает оригинальные иллюстрации и сохранит их в кэше.

Распакуйте ZIP релиза и запустите **Install.cmd**. Дождитесь завершения копирования — Codex Doki запустится автоматически.
Для запуска откройте `%LOCALAPPDATA%\CodexDoki\Start-Doki.cmd`.
Затем меню профиля → Настройки → Внешний вид → Doki Theme.

Права администратора и дополнительные пакеты Python для стандартной установки не нужны.
Codex и иллюстрации не включены в релиз: используются локальная установка и официальный сервер Doki.
В некоторых темах оригинального расширения встречаются иллюстрации для взрослых.

Копия использует отдельный профиль интерфейса `Codex-Doki`; может потребоваться вход.
Проекты, история чатов и служебный каталог `.codex` могут быть общими с основным Codex.

## Проверка, обновление и удаление

```powershell
py -3 install.py check
py -3 install.py install --offline
py -3 install.py uninstall
```

`check` проверяет совместимость без копирования приложения и скачивания картинок.
`--offline` использует только кэш `%LOCALAPPDATA%\CodexDokiCache` и работает после скачивания всех иллюстраций.
Для нестандартных путей доступны `--codex-path`, `--cache-path`, `--install-dir`.
`--extension-path` — необязательная возможность использовать другой каталог тем из локального расширения Doki.
Подробности в `py -3 install.py --help`.

Для удаления закройте копию и запустите **Uninstall.cmd**. При нестандартном пути передайте
его через `--install-dir`. Профиль интерфейса, чаты и проекты сохраняются.
Для обновления удалите копию и создайте её снова. Копия не обновляется вместе с Microsoft Store.

Другие версии Codex не проверены: экспериментальная установка требует `--allow-unsupported`.
Проверки структуры архива остаются обязательными. [Ограничения и диагностика](docs/COMPATIBILITY.md).
