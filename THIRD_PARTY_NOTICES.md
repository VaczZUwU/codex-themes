## OpenAI Codex

The installer operates on the user's own Codex installation. OpenAI executables, runtime packages,
and native translation catalogs are not included in this repository or its release ZIP.
Native labels are extracted locally for UI language matching during installation.

Codex and OpenAI are names of their respective owners. This project is independent and unofficial.
Installation modifies the local copy's executable signature; neither CSP nor archive integrity checks
are disabled. The expected archive integrity hash in the copied executable is updated instead.
